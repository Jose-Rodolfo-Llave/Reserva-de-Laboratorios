# Reserva de Laboratorios

Prototipo web para gestionar las reservas de los laboratorios de cómputo
de la Escuela de Ingeniería de Sistemas.

## Módulos del sistema

- Consulta de disponibilidad
- Registro de reservas
- Visualización de reservas existentes
